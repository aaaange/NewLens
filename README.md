### ✅ 주요 기능 summary

---

1️⃣ 전 세계 뉴스 검색

- 기간, 카테고리, 키워드 기반 사용자 맞춤형 검색 기능

- 마인드맵 기반 연관 키워드 탐색 기능

2️⃣ 실시간 핫 키워드 및 랭킹 제공

- 실시간 TOP10 글로벌 키워드 랭킹

- 국가별 키워드 뉴스 노출 현황

3️⃣ 주요국 지도 시각화 제공

- 전 세계 뉴스 언급량 및 감정 분석 결과를 지도에 시각화

- 국가별 긍/부정 비율 및 언급량을 색상으로 표현

4️⃣ 국가별 뉴스 심층 분석 대시보드

- 뉴스 리스트, 요약, 감정 변화 그래프, 워드클라우드 제공

- 국가 간 비교 기능 제공

5️⃣ 맞춤형 개인 기능

- 뉴스 스크랩 및 관심 키워드 기반 추천 피드 제공

- 회원 정보 조회 및 닉네임 수정 기능

# 🧠 AI 기술 적용

- Facebook M2M100을 활용한 다국어 번역
- BERT 기반 감정 분석 및 KoBERT 기반 카테고리 분류
- Komoran + TF-IDF 기반 키워드 추출
- 실시간 데이터 파이프라인으로 자동 수집 → 분석 → 저장까지 자동화

---

# 📦 데이터 흐름 및 처리

- 국내외 뉴스 수집: Naver News API + thenewsapi 활용
- 실시간 감정 분석, 언급량 측정, 워드 클라우드 생성
- Elasticsearch 기반 뉴스 검색 및 유사 기사 추천

---

# 💡 프로젝트 특장점

- 다양한 필터링과 마인드맵 탐색으로 관심 키워드 신속 탐색
- 실시간 반영되는 글로벌 키워드 랭킹
- 감정 및 언급량 시각화로 직관적 이해
- 맞춤형 피드와 스크랩으로 개인화된 뉴스 경험 제공
